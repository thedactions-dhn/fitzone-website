Cara Menggunakan
Panduan Akses Mudah

Ikuti 6 langkah ini untuk memulai perjalanan kebugaran Anda hari ini.

Langkah 01
Buka Website
Akses FitZone dari browser HP atau laptop. Tidak perlu install — langsung buka dan gunakan.
Langkah 02
Pilih Program
Pilih program latihan sesuai tujuan: Pemula, Menengah, atau Lanjut. Bisa juga buat program sendiri.
Langkah 03
Gunakan Tracker
Buka bagian Workout Tracker, pilih sesi Pagi atau Sore, lalu centang setiap gerakan yang selesai.
Langkah 04
Aktifkan Timer
Gunakan Stopwatch atau Interval Timer HIIT untuk mengontrol waktu latihan dan istirahat.
Langkah 05
Cek Progres
Pantau konsistensi latihan mingguan di bagian Progress. Streak membantu Anda tetap termotivasi.
Langkah 06
Hitung BMI
Masukkan berat dan tinggi badan di kalkulator BMI untuk mendapatkan rekomendasi program yang sesuai.
